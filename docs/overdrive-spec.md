> **앱 이름: OVERDRIVE.** 컨셉: 네 실제 운동 데이터를 게임화된 **전투력(Combat Power)** 점수로 바꾸고, **기록 하나하나 할 때마다 화면이 개씨발 폭발하는** 뽕맛 피드백으로 운동을 중독적으로 만든다. 한계를 넘으면 **OVERDRIVE 진입** = 화면 터짐.
> 톤: **B급 과잉 감성 = 기능이다.** 렌즈플레어·스크린셰이크·네온·아케이드 사운드 — 오글거림을 무기로. 단 아래 **0. 작업 규칙 + §9 컴플라이언스**는 절대 사수.

## 1. 프로젝트 개요

**한 줄:** 실제 운동 데이터(헬스킷/헬스커넥트 + 근력 로깅 + 체성분 + 체력 테스트)를 게임화된 **전투력 점수**로 환산하고, **기록할 때마다 폭발하는 뽕맛 피드백 + 오라 카드**로 운동을 중독적이게 만드는 앱. 이름 = **OVERDRIVE.**

**1차 사용자:** 빌더 본인(dogfooding). 성공 기준 = "내가 매일 쓰고 운동에 도움 + 기록할 때마다 개꼴림." 다른 유저/바이럴은 보너스.

**차별점 (절대 사수):**
1. **실데이터 = "인증" 전투력** (센서/워치/Strava 검증, 자기보고만 X)
2. **근거 기반 지속가능 프로그래밍** (근육 주2회·RIR 1–3·점진적 과부하·인터벌·휴식)
3. **JUICE 엔진** — 기록마다 기폭발(이게 OverDrive의 시그니처 뽕맛)
4. **오라 카드** — 운동 후 셀카에 오라 입힌 공유 카드(바이럴 자산)
5. **포용 + 반수치심** — 배틀 오라 ↔ 글로우 미감 선택, 남녀·건강 중립

## 2. 프로덕트 원칙

- **뽕맛 = 도파민 루프 = 로깅 습관 = #1 유지 레버.** 단 "약빤 느낌"은 **이펙트·사운드·강도**로 내는 거지 약물 단어로 내는 게 아님(스토어 등급/건강 톤).
- **JUICE는 절대 마찰 X** — 화려함이 로깅을 느리게 하면 실패. 짧고·강하고·스킵 가능.
- **뽕맛은 "벌어야" 의미 있다** — 강도/PR/검증 데이터에 비례. 빈 컨페티 X.
- **반수치력 in 하이프** — 하이프는 "네 전투력이 올랐다 / 나타난 것 자체"를 축하하지, 낮은 숫자를 조롱 X. 컨디션 안 좋아도 나타나면 (작은) 폭발은 준다.
- **재미는 진짜 위에** — 전투력은 **재미용 자체 산식(과학적 지표 아님)** 임을 UI에 명시.
- **🔥 그래픽은 히어로다 — 한계까지 부숴라.** 이펙트 퀄리티가 OverDrive의 정체성. Skia/GPU가 허용하는 **끝까지** 밀어붙인다(§6.4). "그럭저럭 멋진" 건 실패로 간주. (단 아래 "JUICE는 마찰 X" 철칙은 사수.)

## 3. 기술 스택

### 프론트엔드 (결정됨)
- **React Native + Expo (dev client) + TypeScript.**
- **🔥 그래픽/이펙트 (최우선 — 한계까지, §6.4):** **@shopify/react-native-skia**(VFX 코어 — SkSL 커스텀 셰이더로 에너지 오라·글로우·디스토션·크로마틱·프랙탈/터뷸런스 노이즈·디스플레이스먼트·파티클·블러; **GPU 다이렉트 + 별도 렌더 루프 = frame-perfect, JS 브리지/로깅 안 막음; Flutter가 쓰는 그 Skia 엔진과 동일 → VFX 천장 동급**) + **react-native-reanimated 4**(슬램·스크린셰이크·슬로모·스프링; 셰이더 uniform을 매 프레임 UI 스레드 구동 — **New Architecture/Fabric 전용, RN 0.81+**). **(3D — 스코프 포함)** react-three-fiber(WebGL2) / react-native-wgpu(WebGPU) + TSL — 3D 오라·파티클 시뮬·3D 전투력 비주얼. **2D Skia 토대 위에 레이어드**(복잡도↑이지만 스코프 확정). **(옵션)** Rive / Lottie — 디자이너제 모션그래픽(레벨업·배지).
- 사운드: 사운드 재생 라이브러리(예: expo-av / react-native sound 계열). **햅틱:** expo-haptics(또는 RN haptic).
- 헬스: `react-native-health`(HealthKit) + `react-native-health-connect`(Android), 또는 통합 래퍼.
- 카메라/세그멘테이션: `react-native-vision-camera`(프레임 프로세서) + ML Kit(Selfie Segmentation / Pose Detection / Text Recognition·OCR).
- 차트: Skia 또는 react-native-svg.
- 상태: Zustand + React Query.
- **Swift/Kotlin 불필요:** 위 전부 **RN/JS/TS로 구현**됨(플러그인이 네이티브를 래핑). 네이티브 모듈은 *기존 플러그인 없는 기능*이나 *Skia를 넘는 단일 극한 이펙트(Metal/Core Image)* 같은 **희귀 에스케이프 해치로만** — **본 스펙 범위는 전부 RN + Skia로 커버.**

### 도메인 백엔드 — **DECISION (사용자 확인)**
> 사용자는 인증·rate limiting 등 cross-cutting을 처리하는 **자체 플랫폼/게이트웨이** 보유 → 이 백엔드는 **비즈니스 도메인 서비스(thin).**
- **기본 추천: Node.js + NestJS + TypeScript + PostgreSQL** (RN과 같은 언어, I/O 워크로드 적합, 빠른 출시).
- 대안: **Java + Spring Boot**(학습/엔터프라이즈) / **Python + FastAPI**(서버 AI 비중 크면).
- **DB:** PostgreSQL(관계형 — 리그/리더보드/소셜). **배포:** AWS Elastic Beanstalk(쉬움) → ECS/Fargate. DB는 RDS. 스토리지 S3.

### AI/외부
- **STT** + **LLM 구조화 파싱**(음성→`{exercise, sets, reps, weight, rir}`): **서버사이드** 호출, 키 숨김.
- **Strava** 웹 API(러닝 자동 임포트). 나이키런 등은 HealthKit/Health Connect 경유.

## 4. 아키텍처

```
[RN 앱 (Expo/TS)] ─HTTPS→ [사용자 플랫폼/게이트웨이: 인증·rate limit·라우팅] ─(검증 신원)→ [도메인 백엔드(NestJS)]
                                                                                          ├─ PostgreSQL(RDS)
                                                                                          ├─ 서버 AI(STT+LLM, 키 숨김)
                                                                                          └─ push 트리거
[온디바이스] HealthKit/Health Connect 읽기→요약 동기화 · 오라카드/폭발 이펙트 생성(Skia, 서버 부하 X)
```
**도메인 백엔드 책임(게이트웨이가 인증/rate limit 해도 남음):** 도메인 인가(소유권·멤버십) / 게이트웨이 신원 신뢰 + 직접접근(우회) 차단(네트워크 격리·mTLS·토큰 재검증) / 도메인 검증·비즈니스 한도 / 데이터 무결성 + 스파이크 확장.

## 5. 데이터 모델 (PostgreSQL 개념 스키마)

- **CardioLog**: `id, session_id, modality, duration_sec, rounds, rpe, distance_m, source`
- **BodyComp**: `id, user_id, date, weight, body_fat_pct, muscle_mass, source(manual|ocr|smart_scale), raw(jsonb)`

- **PowerEvent**: `id, user_id, session_id, tier(1..4), delta, reason(set|pr|session|streak|levelup), created_at` *(JUICE 트리거 로그)*
- **Program / League / LeagueMembership / Friendship / Streak / AuraCard**: (이전 스펙과 동일 구조)

## 6. 핵심 기능 스펙

### 6.1 운동 로깅 (마찰 최소)
- **음성(메인, 근력):** 마이크→STT(서버)→LLM 파싱(서버)→확인/수정→저장. 카메라 불필요.
- **빠른 탭(폴백):** 지난 기록 **프리필 + "지난 세트 반복" 버튼**, 1–2탭 완료.
- **자동 임포트(유산소):** Strava/HealthKit/Health Connect = "검증" 데이터.
- **점진적 과부하:** 각 운동 "지난: Xkg×Y" 표시 → 넘기면 `is_pr=true` → **JUICE T3 발동.**
- CV 횟수: 집/맨몸·폼체크 옵션만(헬스장 메인 X). 워치 자동감지: "제안+확인" 보조.

### 6.2 프로그램 엔진 (근거 기반 기본 템플릿)
- 월 상체A / 화 하체A / 수 인터벌 / 목 상체B / 금 하체B / 토 인터벌 / 일 휴식.
- 원칙: 각 근육 주2회 · RIR 1–3 · 점진적 과부하 · 인터벌 주2회 · 휴식 1일. (편집 가능, 분할 토글은 후순위)

### 6.3 전투력(Combat Power) — **재미용 자체 산식(과학 아님, UI 명시)**
- 바스켓(최근 7일 + 체력 마커): 근력 볼륨 + 세션 + 컨디셔닝 + 연속 + 규율(단백질/휴식) + 리컴프 진행(스무딩) + 체력 마커(VO2max/악력/푸시업/sit-to-stand/균형/데드행).
- **trust-tiering:** 검증 데이터(워치/임포트/센서) 가중↑, 자기보고 구분, `verified_ratio` 저장.
- 등급(자체·오리지널): 일반인→루키→파이터→워리어→비스트→괴수→초월자.
- breakdown 투명 + "재미용 자체 산식" 라벨.

### 6.4 ⚡ JUICE 엔진 (뽕맛/기폭발) — **OverDrive의 심장**
> 기록·진행 액션마다 **시각 + 사운드 + 햅틱**이 동시에 터지는 보상 시스템. 강도는 **노력/PR/검증 데이터에 비례.** B급 과잉 = 의도된 미학.
>
> **🔥 그래픽 디렉티브 (최우선·타협 없음): 이펙트를 Skia/GPU 한계까지 부숴라.** "그럭저럭"은 실패다. **SkSL 커스텀 셰이더를 직접 작성**하고, **ShaderToy 데모(GLSL)를 SkSL로 포팅**해 에너지 오라·폭발·잔상·디스토션·렌즈플레어를 만들 것. 멀티패스 셰이더 · 파티클 수백 개 · 블룸/글로우/크로마틱 애버레이션 · 슬로모를 **GPU에서 frame-perfect**로. **진짜 병목은 프레임워크가 아니라 셰이더/디자인 실력 → 이펙트 퀄리티에 반복 투자(여러 번 다듬기)할 것.** Swift 불필요 — Skia로 끝까지 가고, 정말 Skia를 넘는 단일 hero 이펙트만 네이티브 모듈(Metal) 에스케이프 해치. (단 아래 철칙: **로깅 속도 > 화려함** 사수.)

**에스컬레이션 티어 (뽕맛 사다리):**
| 티어 | 트리거 | 연출 (≈길이) |
|---|---|---|
| **T1** | 세트 1개 기록 | 빠른 에너지 팝 + "+N" 전투력 플로트업 + 틱 사운드 + 라이트 햅틱 (≤0.4s, 스킵 가능, 로깅 블록 X) |
| **T2** | 견고한 세트 / 목표 달성 | 컬러 플래시 + 작은 파티클 버스트 + 청크 사운드 + 미디엄 햅틱 (≈0.6s) |
| **T3** | **PR(지난 기록 돌파)** / 실패 직전 하드셋 | **OVERDRIVE 진입** — 스크린 셰이크 + 파티클 폭발 + 슬로모 + 오라 점화 + 베이스 히트 + 강한 햅틱 + 전투력 **오도미터 슬램**(숫자가 글로우와 함께 확 차오름) (≈1.2s, 탭으로 스킵) |
| **T4** | 세션 완료 / 연속(streak) / 레벨업 | 풀스크린 슈퍼노바 + 자체 콜아웃(예: "OVERDRIVE!", "REDLINE!", "MAX POWER!") + **오라 카드 자동 생성(공유)** + 등급/연속 배지 |

**OVERDRIVE MODE:** PR/하드셋/브루탈 세션에서 화면이 "오버드라이브 상태"로 진입 — 컬러 서지 + 스피드라인 + 오라 강화 + 전투력 게이지 스파이크. (세션 중 전투력 게이지가 차오르다 임계 도달 시 발동)

**연출 구현 가이드 (Claude Code):**
- 비주얼: **Skia**(셰이더 글로우/파티클/폭발, 이미지 디스플레이스먼트) + **Reanimated**(슬램/셰이크/슬로모 타이밍). 렌즈플레어·크로마틱애버레이션·스캔라인(CRT)·코믹 "POW/BOOM" 버스트·네온 = B급 미학.
- 사운드: 펀치 SFX·베이스 드롭·아케이드 파워업·**자체 콜아웃**(트레이드마크 콜아웃 금지). 토글(헬스장은 무음+햅틱만 가능).
- 햅틱: 티어별 점증 럼블.

**철칙:**
- **T1–T2는 절대 로깅을 막지 않는다**(비동기, 짧게, 스킵). 큰 연출(T3–T4)만 특별하게 — 아껴야 안 질림.
- **강도 = 노력/검증에 비례** → 뽕맛이 "벌은" 느낌(의미 있는 도파민).
- **유저 조절**: `juice_intensity`(풀/중/미니멀), `sound_on` 설정 제공.
- **반수치심**: 컨디션 나빠 약한 세트여도 나타나면 T1 팝은 준다(처벌 X).
- `PowerEvent`에 티어/델타/사유 로깅(전투력 추이·디버그용).

### 6.5 헬스 연동
HealthKit(iOS)/Health Connect(Android) **타입별 런타임 권한**. 온디바이스 읽기→요약 동기화. Strava OAuth 임포트.

### 6.6 체성분 업로드
수동 + (AI)InBody 결과지 사진 OCR + 스마트체중계(헬스 경유). **트렌드 중심 + 스무딩**(BIA 노이즈), 조건 표준화 안내, **건강 프레임(반수치심).** InBody API(유료/B2B)는 후순위.

### 6.7 오라 카드 (바이럴 자산 = T4 페이오프)
운동 완료/PR → 셀카 → **세그멘테이션**(ML Kit) → **오라/폭발 합성**(Skia 셰이더) → 전투력·등급 오버레이 → 공유 카드 + 앱 핸들 워터마크. **미감 선택**: 배틀 오라(불꽃/전기) ↔ 글로우/광채 ↔ 네온. **오리지널 디자인만.** (정지 사진 기준, 라이브 영상 AR은 후순위)

### 6.8 리그/소셜/경쟁 — 바이럴 + 뽕맛 경쟁 엔진 🔥
> 경쟁은 **"이길 수 있게"** 설계(향상/꾸준함 기준 → 초보·여성도 이김) + opt-out. 단 **경쟁 표면은 존나 많이**, 경쟁 뽕맛은 **JUICE와 직결.**

**경쟁 표면 (전부 비교 가능):**
- **친구 리더보드** — 친구들과 직접 비교(전투력·주간 향상%·연속·볼륨·체력 마커). "전부 다 비교."
- **크루/반 (프라이빗 그룹)** — 친구·반친구·짐메이트로 **비공개 그룹 생성/초대** → 그룹 리더보드 + 그룹 챌린지. (반친구들 케이스)
- **또래 리그** — 비슷한 수준 ~30명 주간 리그, 승급/강등(이길 수 있는 글로벌 대안).
- **결투 (1:1 Duel)** — 친구에게 **1주 대결** 신청(누가 더 기록/향상/전투력 상승). 직접 경쟁 뽕맛.
- **주간 챌린지/이벤트** — 앱/그룹 단위(예: 이번 주 최대 볼륨·최장 연속) + 리더보드 + 보상 배지.
- **비교 뷰** — 친구/크루/또래 코호트 대비 **모든 스탯**(전투력·볼륨·연속·향상%·체력 마커)을 한눈에.

**경쟁 뽕맛 (JUICE 직결):**
- 순위 **추월** / 결투 **승리** / 리더보드 **상승** / 라이벌 **제침** → **JUICE T3~T4 폭발 + 공유 카드 자동 생성**("내가 X 제쳤다", "크루 1위", "결투 승리", "S랭크").
- "친구가 너에게 결투 신청" / "X가 네 순위를 추월" 푸시(복귀 트리거).

**바이럴 경쟁 루프:**
- **결투·그룹 초대 링크** = 친구 유입(경쟁 유발 + 획득 동시) + 레퍼럴.
- **공유 카드**(순위·결투·전투력·등급) = 바이럴 자산, 핸들 워터마크.

**가드(지속가능):** trust-tiering(경쟁 리더보드는 **검증 데이터 가중** = 치트 방지 + 차별점) · **향상/꾸준함 metric**(절대 근력 X → 반수치심) · **경쟁 opt-out** + 친구 스트릭(상호 책임).

### 6.9 안티치트 / trust-tiering
예방 X, **검증 데이터 가중**. 리더보드는 검증(임포트/센서) 위주 + 가벼운 타당성 체크(말 안 되는 점프). 개인 기록은 자유.

## 7. AI 로깅 파이프라인

## 8. 로드맵 (이 순서로)

- **Phase 0 — 훅 검증(권장):** 웹/PWA **오라 카드 + 기폭발 데모** + 틱톡 클립. *Accept:* 셀카→오라+폭발 공유 이미지 생성, 외부 반응 측정 가능.
- **Phase 1 — 로컬 MVP(개인용):** 백엔드 없이 온디바이스 저장. 빠른탭/수동 로깅 + 점진적 과부하 + 프로그램 + 전투력(로컬) + 단백질/휴식 + **JUICE 엔진(T1–T4)**. *Accept:* 오프라인 동작, 기록할 때마다 폭발, 빌더가 매일 쓸 수준.
- **Phase 2 — 백엔드 + 계정 + 헬스 + 동기화 + 음성 로깅.** *Accept:* 로그인/동기화, 헬스·Strava 임포트, 음성 로깅, 키 서버에만, §9 충족.
- **Phase 3 — 오라 카드(네이티브) + 공유 + 3D 레이어.** 2D Skia 오라/폭발 먼저 → 그 위에 **3D(R3F/WebGPU) 오라·파티클** 레이어드. *Accept:* PR/완료→셀카→오라 카드→공유(오리지널 에셋), 2D 토대 위 3D 이펙트 동작.
- **Phase 4 — 소셜 + 경쟁 엔진(§6.8) 🔥:** 친구/크루(반)/또래 리그 리더보드 + **결투(1:1)** + 주간 챌린지 + 비교 뷰 + **경쟁 뽕맛(추월/승리 → JUICE + 공유 카드)** + 초대 링크(바이럴) + trust-tiering. *Accept:* 친구·그룹·리그 리더보드 동작, 결투 생성/판정, 추월·승리 시 JUICE+공유 카드, 검증 데이터 가중, opt-out.
- **Phase 5 — 체력 마커/테스트 데이 + 체성분.** *Accept:* 테스트→스탯 시트→전투력 갱신, 체성분 트렌드(스무딩).
- **Phase 6 — 폴리시 + 출시 + 수익화(구독/어필리에이트) + 푸시.** *Accept:* 개인정보방침·헬스 정책 충족, 구독 플로우, 스파이크 대응.

## 9. 제약 & 컴플라이언스 (필수)

- **헬스 데이터:** 개인정보처리방침 필수 · 광고/마케팅/데이터마이닝/판매 금지(제3자 포함) · HealthKit 데이터 iCloud 저장 금지 · 거짓 데이터 쓰기 금지 · 수집 타입 명시 · 헬스 앱 심사 강화 · Android Health Connect는 읽고/쓰는 타입 전부 공개 선언 + 맥락 권한.
- **수익화:** 구독 + 어필리에이트 (헬스 데이터 판매/광고 타깃팅 금지).
- **IP/에셋:** **오리지널만.** 드래곤볼/사이어인/Limit Break/Final Fantasy 등 이름·디자인·에셋·사운드·콜아웃 금지. 오라/폭발/콜아웃 자체 제작.
- **브랜드 가용성(출시 전 확인):** "OverDrive"는 흔한 단어이자 기존 브랜드(예: 도서관 디지털미디어 OverDrive)가 있음 — **피트니스는 다른 클래스라 통상 OK 가능성이 크지만, 출시 전 상표·앱스토어 이름·도메인·핸들 가용성 검증 필수.**
- **웰빙:** 반수치심(하이프 포함) · 체지방/외형은 건강·향상 프레임 · 절대 강자만 보상 X.
