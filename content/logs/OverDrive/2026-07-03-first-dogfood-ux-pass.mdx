## 배경

Reploom(구 OverDrive) 첫 TestFlight 빌드(Build 4)가 드디어 폰에 들어갔다. 빌더 본인의 첫 평결: **"너무 허접하고 사용성도 별로다."** 아픈 지점을 물으니 네 영역 전부 — 시작/로딩, 기록 흐름, 홈 화면, 버벅임/그래픽. 맥락은 "설치 후 둘러만 봄" (첫인상 평가, 실운동 전).

이건 6월 30일에 기록된 blocked 전략 결정("진전이 cosmetic 축에 몰림, 실사용 미검증")의 입력값이다. 결론: **신규 기능 동결, 첫 5분 경험 수리.**

## 감사

8개 표면(부트 TTI / 홈 IA / 기록 루프 / 셰이더 성능 / 온보딩 / 파워·에볼루션 / 주변 화면 / 공통 품질)을 병렬 감사, P0/P1 후보는 전부 코드 반박 검증을 거침. 결과: **45건 확정 (P1 7, P2 38), 전부 file:line 증거 보유.**

스펙 사수 항목 위반 2건이 뼈아팠다:

1. **§6 "JUICE/로깅은 아무것도 못 막는다" 위반** — 기록이 Gemini 네트워크 응답(최대 7초)을 기다린 뒤에야 저장됐다. 게다가 몸 지도 첫 탭은 1.6초 풀스크린 enter 연출에 먹혀서 기록 시작까지 2~3탭.
2. **§9 반수치심 위반** — 신규 유저가 데이터 0인 상태에서 열자마자 "라이벌에게 20 뒤처짐 — 따라잡아".

그리고 치명타: **빌드에 AI 엔드포인트가 아예 안 들어갔다.** `.env`는 gitignore, eas.json엔 env 블록 없음 → EAS 클라우드 빌드의 `QUICKLOG_ENDPOINT`가 빈 문자열로 컴파일 (IPA 번들 바이너리 grep으로 실증). 음식/음성 기록이 전부 죽은 채 출고됐고, 유저 화면에 ".env" 개발자 문구가 노출됐다.

## 수리 (커밋 41b3885, 40건)

- **로컬-퍼스트 로깅**: 온디바이스 룰 파서 우선 → 즉시 저장+JUICE 발화, AI는 폴백 전용(7s→3.5s). 음성 27s 락 → 8s + 취소 가능.
- **암묵 세션은 무음 시작**: 몸 지도/유산소 탭이 같은 제스처에서 픽커를 연다. 연출은 명시적 용광로 진입에만.
- **키보드 3종**: persistTaps + 자동 인셋 + submitBehavior(연속 기록).
- **엔드포인트**: config.ts 기본값 + eas.json 3개 프로파일 env 주입. ".env" 문구 전멸.
- **라이벌 시딩**: 신규 유저는 동률 시작, 뒤처짐 스폰 불가.
- **성능**: SkSL 첫 기록 시점 동기 컴파일 제거(모듈 레벨 캐시), T1/T2 팝 픽셀 루프 축소, AmbientAura 유휴 시 리페인트 중단.
- **부트**: 병렬 하이드레이션, iOS 스플래시 이미지, 상태바 라이트, 폰트 실패 폴백.
- **기타**: 터치 타겟 44pt, 프레스 피드백+햅틱, 에볼루션 사진 유실 방지, 랭킹 로딩/리트라이, 온보딩 skip 시 입력 보존, Disconnect 확인 다이얼로그 등.

검증: `tsc` 0 에러, jest **19 suites / 137 tests 전부 PASS** (직접 재실행).

## 교훈

1. **첫인상은 P2의 합이다.** P0 하나 없이도 "허접"이 나온다 — 45건 중 38건이 P2였고, 그 합이 품질 바닥선을 결정했다.
2. **스펙에 써놓고도 어겼다.** "로깅은 1ms도 안 막는다"를 §6에 박아놓고 코어 루프가 네트워크를 기다리고 있었다. 스펙은 문서가 아니라 감사 항목이어야 한다.
3. **gitignored .env는 클라우드 빌드에 존재하지 않는다.** 서명 빌드 스모크 테스트 없이 배포한 대가.
