무료 Build 13 심사를 철회한 뒤 결제 기반 source를 곧바로 production으로 올리지 않고 서로 독립적인 staging 단위로 나눴다. Build 14 바이너리, D1 구독·쿼터 스키마, 정책 사이트 preview는 반영했지만 Apple IAP/entitlement secret이 필요한 Worker와 실제 고객 traffic은 기존 Build 13 세대를 유지했다.

첫 remote migration은 두 번 모두 `incomplete input: SQLITE_ERROR [code: 7500]`으로 atomic rollback됐다. `b0ead93`에서 SQL 주석을 제거한 가설도 같은 오류로 반증됐다. `7f4560d`는 canonical trigger migration을 임시 atomic import로 만들고 pinned Wrangler의 file-ingestion 경로로 실행한 뒤 같은 filename을 `d1_migrations`에 기록하는 runner를 추가했다. remote 적용은 14 queries / 24 rows written으로 끝났고 `ai_*` object 11개, pending migration 0, 기존 ranking 4행, `quick_check=ok`, 외래키 오류 0을 다시 읽었다.

Build 14는 device archive와 App Store export를 통과했다. IPA `/tmp/Reploom-14-export-local-account/Reploom.ipa`의 SHA-256은 `6ba9ebbf6523adb12ccc44942c6cfebcb7b8745a9bc3ffd1a1942bb1e37fe49a`다. Apple validation과 upload 뒤 resource `ad2c1d7a-74f9-4516-94be-0c3a226e15d6`가 `VALID` / `APP_STORE_ELIGIBLE`, minimum iOS 16.4, encryption false로 읽혔다. 버전 1.0은 여전히 Build 13을 가리키고 Build 14 relationship은 `data:null`이므로 App Review에 연결됐다고 기록하지 않았다.

새 website source는 production 대신 `https://14bd35fa.reploom.pages.dev`와 `https://codex-usability-cockpit.reploom.pages.dev`에 noindex preview로 올렸다. 다섯 경로는 200이었고 redirect 뒤 HTML/CSS hash가 추적 파일과 같았다. production Pages와 Worker는 기존 ID를 유지한다.

기능 검증은 Worker 44 tests, D1 remote readback, Apple validation/upload와 ASC 상태 조회까지다. 품질 검증은 IPA bundle/version/build/architecture/entitlement/금지 문자열 scan과 preview byte hash까지다. 제품·워크플로 검증은 완료되지 않았다. 필수 Worker secret 5개, 실제 TestFlight/Sandbox purchase→entitlement→quota→restore, truthful subscription review screenshot, tax/private gate, subscription `READY_TO_SUBMIT`, Build 14/version/첫 구독 연결, 새 App Review 제출이 남았다. `Loading the App Store price…` / `Subscription unavailable`가 보이는 기존 simulator 캡처는 심사 자료로 쓰지 않는다.

구현 커밋: `b0ead93`, `7f4560d`. 상태 기록 커밋: `da28116`.
