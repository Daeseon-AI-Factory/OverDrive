## 무엇

범위 결정(종합건강이되 저마찰) 후 Phase 1 첫 발. 음식/수면 자동연동은 Phase 2지만, **지금 마찰 0짜리 규율 입력**은 가능: 오늘 단백질 챙김 ✓ / 잘 잠 ✓ 한 탭.

- DB v3: `discipline`(user_id·date·protein·rest) 테이블. fresh는 SCHEMA_V1, 기존(v2)은 v2→v3 `CREATE IF NOT EXISTS`.
- `disciplineRepo`: getToday/setToday(upsert per day)/countSince(7일 protein·rest 일수 + 추적일수 days).
- `combatPowerRepo.buildInput`: `days>0`(추적 시작)이면 `discipline:{proteinDays,restOkDays}` 활성, 아니면 `null`(renorm out). → **규율 안 쓰는 동안은 전투력 안 깎임(안티수치심/graceful), 쓰기 시작하면 반영.**
- `DisciplineCard`(오늘 탭): 단백질/수면 원탭 토글 → setToday → CP 재계산 → 켜면 T1 팝. focus 시 오늘값 로드.
